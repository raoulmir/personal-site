# Raoul-Sebastian Miron - Personal Website

A personal website built with Vue.js, featuring a retro terminal aesthetic.

## Features

- Terminal/retro-inspired UI with window-like content panels
- SPA routing between About Me, Contact, and Homepage
- Clean, modular component architecture

## Getting Started

1. Clone the repository: `git clone <url>`
2. Open `index.html` in a web browser
3. No build step required - pure Vue SPA
